01Funcionamiento de React

React organiza la interfaz en componentes que reúnen la estructura visual y la lógica relacionada. Cada componente describe qué debe mostrarse; cuando cambian los datos, React actualiza la interfaz correspondiente.

Un elemento React puede crearse con React.createElement. La llamada recibe el tipo de elemento, sus propiedades y, opcionalmente, sus hijos.

const titulo = React.createElement(
  "h1",
  null,
  "Camisa de Algodón"
);

JSX ofrece una sintaxis más legible para describir esos elementos. Una herramienta de compilación transforma JSX antes de que el navegador ejecute la aplicación.

02Elementos React con JSX

JSX permite escribir una estructura parecida a HTML dentro de JavaScript. Las etiquetas representan elementos y pueden incluir atributos y elementos hijos.

Una lista de productos

function ListaProductos() {
  return (
    <ul>
      <li>Camisa de Algodón - $2999</li>
      <li>Pantalón - $4999</li>
      <li>Zapatillas Deportivas - $6999</li>
    </ul>
  );
}

Las etiquetas JSX deben cerrarse correctamente. Si un elemento no tiene hijos, puede escribirse como etiqueta autocerrada, por ejemplo <ArticuloCarrito />.

03Componentes y anidamiento

Los componentes se pueden anidar para dividir una interfaz en piezas reutilizables. Las props permiten que el componente padre envíe a cada hijo los datos que necesita.

Carrito con componentes hijos

function CarritoDeCompras() {
  return (
    <section>
      <ArticuloCarrito producto="Camisa de Algodón" precio="$2999" />
      <ArticuloCarrito producto="Pantalón" precio="$4999" />
      <ArticuloCarrito producto="Zapatillas Deportivas" precio="$6999" />
    </section>
  );
}

function ArticuloCarrito({ producto, precio }) {
  return <p>{producto} - {precio}</p>;
}

Cada uso de ArticuloCarrito crea una instancia del componente con valores específicos para sus props.

Componentes anidados para características

function Caracteristica({ texto }) {
  return <li>{texto}</li>;
}

function ListaDeCaracteristicas() {
  return (
    <ul>
      <Caracteristica texto="100% Algodón" />
      <Caracteristica texto="Disponible en varios colores" />
      <Caracteristica texto="Talles: S, M, L, XL" />
    </ul>
  );
}

04Expresiones y listas

Las llaves {} permiten insertar expresiones JavaScript en JSX. Se usan para mostrar variables, acceder a props o calcular el contenido de un elemento.

function Producto({ nombre, precio, enOferta }) {
  return (
    <article>
      <h2>{nombre}</h2>
      <p>Precio: ${precio}</p>
      {enOferta && <strong>En oferta</strong>}
    </article>
  );
}

Renderizar un array con map

const productos = [
  { id: 1, nombre: "Camisa de Algodón", precio: 2999, enOferta: true },
  { id: 2, nombre: "Pantalón", precio: 4999, enOferta: false }
];

function App() {
  return (
    <ul>
      {productos.map(producto => (
        <li key={producto.id}>
          <Producto
            nombre={producto.nombre}
            precio={producto.precio}
            enOferta={producto.enOferta}
          />
        </li>
      ))}
    </ul>
  );
}

map transforma cada producto en un elemento JSX. La prop especial key ayuda a React a identificar de forma estable cada elemento de la lista.

05Estilos en JSX

En JSX se usa className en lugar de class. Los estilos se pueden definir en línea, en una hoja CSS externa o mediante clases elegidas dinámicamente.

AlternativaUsoEjemplo
Estilo en líneaObjeto JavaScript en la prop style; las propiedades CSS se escriben en camelCase.style={{ backgroundColor: "lightblue" }}
Hoja externaImportar un archivo CSS y aplicar sus clases.className="mi-clase"
Clases dinámicasConstruir el valor de className según los datos.className={`producto ${enOferta ? "oferta" : ""}`}

CSS externo y clase dinámica

import "./estilos.css";

function Producto({ nombre, enOferta }) {
  const clase = enOferta ? "producto oferta" : "producto";

  return <article className={clase}>{nombre}</article>;
}

Los estilos en línea se expresan como un objeto, por ejemplo style={{ fontSize: "20px" }}. Para reglas reutilizables y estados visuales, una hoja CSS externa puede mantener los estilos más organizados.

06Ejemplo: aplicación EcoMarket

El ejemplo de EcoMarket combina las ideas de la lectura: la aplicación itera sobre sus productos, delega la presentación en componentes, recibe datos mediante props y aplica clases CSS para dar estilo al contenido.

function ListaEcoMarket({ productos }) {
  return (
    <main>
      <h1 className="titulo">EcoMarket</h1>
      <ul>
        {productos.map(producto => (
          <li key={producto.id}>
            <Producto
              nombre={producto.nombre}
              precio={producto.precio}
              enOferta={producto.enOferta}
            />
          </li>
        ))}
      </ul>
    </main>
  );
}

07Repaso

  • React representa interfaces mediante elementos y componentes reutilizables.
  • JSX describe elementos dentro de JavaScript; no es interpretado directamente por el navegador y se compila como parte del proyecto.
  • Los componentes se componen y anidan; las props transmiten datos de padres a hijos.
  • Las llaves insertan expresiones JavaScript y map ayuda a renderizar colecciones.
  • Usa key para identificar de forma estable los elementos renderizados desde listas.
  • En JSX, usa className; puedes aplicar estilos en línea, hojas CSS y clases dinámicas.
