01ORM y desajuste objeto-relacional

ORM relaciona clases y objetos Java con tablas y filas relacionales. La lectura describe desajustes de granularidad, herencia, identidad, asociaciones y navegación de datos.

ConceptoModelo orientado a objetosModelo relacional
DatosObjetos, campos y tipos JavaFilas, columnas y tipos SQL
IdentidadReferencia (==) e igualdad (equals)Clave primaria
AsociacionesReferencias y coleccionesClaves foráneas y tablas de unión
HerenciaClases y subtiposNo tiene un equivalente universal

No incluye un bloque de código ORM en esta sección.

02JDBC, JPA e Hibernate

JDBC permite ejecutar SQL directamente desde Java y leer resultados con ResultSet. La lectura describe el proceso, pero no incluye un fragmento JDBC para reproducir.

JPA define una especificación para mapear objetos Java a tablas; Hibernate es una de sus implementaciones. Spring Data JPA agrega repositorios y generación de consultas sobre JPA.

Las secciones siguientes recopilan los ejemplos de anotaciones JPA y Spring Data.

03Entidad JPA y tabla

Marcar una clase como entidad

import jakarta.persistence.Entity;

@Entity
public class Usuario {
    // Campos y métodos de la entidad.
}

Elegir el nombre de tabla

import jakarta.persistence.Entity;
import jakarta.persistence.Table;

@Entity
@Table(name = "usuarios")
public class Usuario {
    // Campos y métodos de la entidad.
}

Para persistir una entidad completa necesita, entre otros elementos, un identificador.

04Identificadores JPA

Clave primaria

import jakarta.persistence.Id;

@Id
private Long id;

Identificador autogenerado

import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;

@Id
@GeneratedValue(strategy = GenerationType.IDENTITY)
private Long id;

05Mapeo de campos JPA

Personalizar una columna

import jakarta.persistence.Column;

@Column(name = "nombre_usuario", nullable = false)
private String nombre;

Campo de gran tamaño

import jakarta.persistence.Lob;

@Lob
private String descripcion;

06Relaciones JPA entre entidades

Uno a uno

import jakarta.persistence.JoinColumn;
import jakarta.persistence.OneToOne;

@OneToOne
@JoinColumn(name = "perfil_id")
private Perfil perfil;

Uno a muchos

import jakarta.persistence.OneToMany;
import java.util.List;

@OneToMany(mappedBy = "usuario")
private List<Orden> ordenes;

Muchos a uno

import jakarta.persistence.JoinColumn;
import jakarta.persistence.ManyToOne;

@ManyToOne
@JoinColumn(name = "usuario_id")
private Usuario usuario;

Muchos a muchos

import jakarta.persistence.JoinColumn;
import jakarta.persistence.JoinTable;
import jakarta.persistence.ManyToMany;
import java.util.Set;

@ManyToMany
@JoinTable(
    name = "usuario_rol",
    joinColumns = @JoinColumn(name = "usuario_id"),
    inverseJoinColumns = @JoinColumn(name = "rol_id")
)
private Set<Rol> roles;

07Consultas Spring Data JPA

La anotación @Query permite declarar JPQL en un método de repositorio. @Param vincula el parámetro nombrado de la consulta.

import java.util.List;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.data.jpa.repository.Query;
import org.springframework.data.repository.query.Param;

public interface UsuarioRepositorio
        extends JpaRepository<Usuario, Long> {

    @Query("SELECT u FROM Usuario u WHERE u.nombre = :nombre")
    List<Usuario> findByNombre(@Param("nombre") String nombre);
}

La consulta está escrita en JPQL y usa el nombre de la entidad y sus propiedades Java, no los nombres de tabla y columna SQL.

08Eventos de entidades JPA

@EntityListeners conecta una entidad con una clase que escucha eventos de persistencia.

Entidad

import jakarta.persistence.Entity;
import jakarta.persistence.EntityListeners;
import jakarta.persistence.Id;

@Entity
@EntityListeners(UsuarioAuditoria.class)
public class Usuario {
    @Id
    private Long id;
    private String nombre;
}

Listener

import jakarta.persistence.PrePersist;

public class UsuarioAuditoria {
    @PrePersist
    public void antesDePersistir(Usuario usuario) {
        // Preparar o validar la entidad antes de guardarla.
    }
}

09Objetos embebidos JPA

Clase de valor con @Embeddable

import jakarta.persistence.Embeddable;

@Embeddable
public class Direccion {
    private String calle;
    private String ciudad;

    protected Direccion() {
    }

    public Direccion(String calle, String ciudad) {
        this.calle = calle;
        this.ciudad = ciudad;
    }

    public String getCalle() {
        return calle;
    }

    public String getCiudad() {
        return ciudad;
    }
}

Incluirla con @Embedded

import jakarta.persistence.Embedded;
import jakarta.persistence.Entity;
import jakarta.persistence.Id;

@Entity
public class Usuario {
    @Id
    private Long id;

    @Embedded
    private Direccion direccion;
}

Los campos de Direccion se guardan como columnas de la tabla de la entidad contenedora, salvo que se personalice el mapeo.

10Persistencia: repaso

La persistencia conserva datos más allá de la ejecución de la aplicación y permite recuperarlos en ejecuciones futuras.

La lectura describe JDBC, JPA, Hibernate y Spring Data JPA, pero no presenta un bloque de código JDBC ni un proyecto ejecutable completo.
