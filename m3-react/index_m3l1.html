01React y aplicaciones SPA

React es una biblioteca de JavaScript para construir interfaces con componentes reutilizables. En una SPA (Single Page Application), el navegador carga una página inicial y React actualiza las partes necesarias cuando cambia el estado o el usuario interactúa.

03DOM y DOM virtual

El DOM del navegador

El DOM (Document Object Model) es la representación de una página como un árbol de nodos que el navegador mantiene en memoria. Cada elemento HTML, texto y atributo forma parte de ese árbol. El navegador lo usa para mostrar la página y JavaScript puede consultarlo o modificarlo.

document
└── body
    └── main
        ├── p: "Contador: 0"
        └── button: "Sumar"

La descripción de interfaz de React

En React, el componente no suele modificar directamente esos nodos. Devuelve JSX, que describe qué interfaz corresponde a las props y al estado actuales. React convierte esa descripción en elementos de React y conserva la información necesaria para gestionar las renderizaciones. A esa representación en memoria se la suele llamar DOM virtual: no es el DOM del navegador ni una segunda página visible.

Qué ocurre cuando cambia el estado

Cuando el estado cambia, React vuelve a ejecutar el componente para obtener la nueva descripción. La reconcilia con la anterior, calcula qué debe cambiar y aplica esas actualizaciones al DOM real durante el commit. Así, React puede actualizar el texto del contador sin reconstruir toda la página; el componente, sin embargo, puede volver a ejecutarse.

function Contador() {
  const [cuenta, setCuenta] = useState(0);

  return (
    <div>
      <p>Contador: {cuenta}</p>
      <button onClick={() => setCuenta(valor => valor + 1)}>
        Sumar
      </button>
    </div>
  );
}

Al pulsar el botón, cambia cuenta; React calcula la siguiente interfaz y actualiza el texto correspondiente en el DOM. La reconciliación la gestiona React, no se programa comparando árboles manualmente.

04JSX

JSX permite describir elementos de interfaz dentro de JavaScript. Las expresiones JavaScript se insertan entre llaves y el proyecto necesita una herramienta de compilación como Vite.

Expresión dentro de JSX

function App() {
  const nombre = "Martina";
  const saludo = <h1>Bienvenida, {nombre}!</h1>;

  return (
    <div>
      {saludo}
      <p>Aplicación con React</p>
    </div>
  );
}

export default App;

Función que devuelve JSX

function obtenerSaludo(nombre) {
  return <h1>Bienvenida, {nombre}!</h1>;
}

function App() {
  return <div>{obtenerSaludo("Martina")}</div>;
}

export default App;

Los componentes usados como etiquetas JSX empiezan con mayúscula; una función auxiliar como obtenerSaludo puede llamarse directamente dentro del componente.

Se presenta componentes de clase como alternativa. Para componentes nuevos suele preferirse la forma funcional con hooks.

06Props

Las props son entradas de solo lectura que el componente padre entrega al hijo. Pueden contener valores y funciones.

function Saludo({ nombre }) {
  return <h1>Bienvenido, {nombre}</h1>;
}

function App() {
  return <Saludo nombre="Carlos" />;
}

export default App;

Se muestra la misma idea accediendo a props.nombre; aquí se utiliza desestructuración en los parámetros.

07Estado con useState

El estado pertenece al componente y puede cambiar con el tiempo. Al actualizarlo, React vuelve a renderizar la interfaz.

Contador funcional

import { useState } from "react";

function Contador() {
  const [contador, setContador] = useState(0);

  return (
    <div>
      <p>Se presionó el botón {contador} veces</p>
      <button onClick={() => setContador(valor => valor + 1)}>
        Haz clic
      </button>
    </div>
  );
}

export default Contador;

Se utiliza la forma funcional de actualización para calcular el valor siguiente a partir del estado previo.

Renderizado condicional basado en el estado

function Contador() {
  const [cuenta, setCuenta] = useState(0);

  return (
    <div>
      <p>{cuenta > 0 ? "Se hizo clic" : "No se hizo clic"}</p>
      <button onClick={() => setCuenta(valor => valor + 1)}>
        Haz clic
      </button>
    </div>
  );
}

08Estado en componentes de clase

Inicialización y actualización

import { Component } from "react";

class Contador extends Component {
  constructor(props) {
    super(props);
    this.state = { cuenta: 0 };
  }

  incrementar = () => {
    this.setState(estadoAnterior => ({
      cuenta: estadoAnterior.cuenta + 1
    }));
  };

  render() {
    return (
      <div>
        <p>Contador: {this.state.cuenta}</p>
        <button onClick={this.incrementar}>Incrementar</button>
      </div>
    );
  }
}

El ejemplo muestra la inicialización con this.state y una actualización con setState. La forma funcional suele ser preferible para lógica nueva.

09Hooks: useState y useEffect

Sintaxis general de useEffect

useEffect(() => {
  // Efecto que se ejecuta después del render.
  return () => {
    // Limpieza opcional del efecto.
  };
}, [dependencias]);

Temporizador con limpieza del intervalo

import { useEffect, useState } from "react";

function Temporizador() {
  const [segundos, setSegundos] = useState(0);

  useEffect(() => {
    const intervalo = setInterval(() => {
      setSegundos(valor => valor + 1);
    }, 1000);

    return () => clearInterval(intervalo);
  }, []);

  return <p>Tiempo: {segundos} segundos</p>;
}

La dependencia vacía hace que el intervalo se configure al montar el componente. La función de limpieza lo detiene al desmontarlo.

10useContext

Context permite compartir un valor con componentes descendientes sin pasar props manualmente por cada nivel. La lectura acompaña este tema con un botón que alterna el tema; el ejemplo está reconstruido con Context y estado para expresar ambas ideas correctamente.

import { createContext, useContext, useState } from "react";

const TemaContexto = createContext(null);

function BotonTema() {
  const { tema, cambiarTema } = useContext(TemaContexto);
  const color = tema === "verde" ? "#4CAF50" : "#F44336";

  return (
    <button onClick={cambiarTema} style={{ backgroundColor: color }}>
      Botón
    </button>
  );
}

function App() {
  const [tema, setTema] = useState("verde");
  const cambiarTema = () => {
    setTema(actual => actual === "verde" ? "rojo" : "verde");
  };

  return (
    <TemaContexto.Provider value={{ tema, cambiarTema }}>
      <BotonTema />
    </TemaContexto.Provider>
  );
}

Este ejemplo muestra el patrón válido con createContext, Provider y useContext.

11useReducer

useReducer organiza actualizaciones de estado mediante acciones y una función reducer.

import { useReducer } from "react";

const estadoInicial = { contador: 0 };

function reducer(estado, accion) {
  switch (accion.type) {
    case "INCREMENTAR":
      return { contador: estado.contador + 1 };
    case "DECREMENTAR":
      return { contador: estado.contador - 1 };
    default:
      return estado;
  }
}

function Contador() {
  const [estado, dispatch] = useReducer(reducer, estadoInicial);

  return (
    <div>
      <h2>Contador: {estado.contador}</h2>
      <button onClick={() => dispatch({ type: "INCREMENTAR" })}>
        Incrementar
      </button>
      <button onClick={() => dispatch({ type: "DECREMENTAR" })}>
        Decrementar
      </button>
    </div>
  );
}

14Temporizador EcoMarket

Ejemplo reconstruido a partir de la consigna: contar desde 0 hasta 10, escribir cada nuevo valor en la consola y permitir detener el contador antes de terminar.

import { useEffect, useState } from "react";

function TemporizadorEcoMarket() {
  const [segundos, setSegundos] = useState(0);
  const [activo, setActivo] = useState(true);

  useEffect(() => {
    if (!activo || segundos >= 10) return;

    const temporizador = setTimeout(() => {
      const siguiente = segundos + 1;
      setSegundos(siguiente);
      console.log("Contador:", siguiente);

      if (siguiente === 10) {
        setActivo(false);
      }
    }, 1000);

    return () => clearTimeout(temporizador);
  }, [activo, segundos]);

  function detener() {
    setActivo(false);
  }

  return (
    <section>
      <h2>Ciclo de vida con contadores</h2>
      <p>Contador: {segundos}</p>
      <button onClick={detener} disabled={!activo}>
        Detener contador
      </button>
      {!activo && <p>Temporizador finalizado.</p>}
    </section>
  );
}

export default TemporizadorEcoMarket;

Se usa setTimeout por tick y se cancela en la limpieza del efecto. Así, detener el contador o desmontar el componente evita que queden temporizadores activos.
