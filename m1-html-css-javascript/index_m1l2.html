01Propiedades y reglas

Una propiedad

p { font-size: 30px; }

Varias propiedades

p {
  color: #FF0000;
  font-size: 30px;
}

Resultado

02Tres formas de aplicar CSS

Estilos en línea

<p style="color: blue; font-size: 20px;">Texto con estilo en línea</p>

Estilos incrustados

<head>
  <style>
    p { color: blue; font-size: 20px; }
  </style>
</head>

Hoja externa

<head>
  <link rel="stylesheet" href="estilos.css">
</head>

El atributo style afecta a un elemento. style dentro de la cabecera agrupa reglas del documento. link permite reutilizar un archivo CSS entre páginas.

03Cascada y sobrescritura

HTML

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Ejemplo de CSS en Cascada</title>
  <link rel="stylesheet" href="estilo.css">
</head>
<body>
  <main>
    <section>
      <p>Texto en el primer párrafo. </p>
      <p class="resaltado">Texto en el segundo párrafo resaltado. </p>
    </section>
  </main>
</body>
</html>

CSS

section { font-size: 20px; color: #000000; }
p { font-size: 24px; color: #FF0000; }
p.resaltado { font-size: 30px; color: #0000FF; }

Resultado

Las reglas aplicadas directamente a los párrafos sustituyen los valores heredados de section. p.resaltado es más específico que p.

04Sintaxis y unidades

h1 {
  color: red;
  font-size: 5em;
}

El selector es h1; cada declaración contiene una propiedad, dos puntos y un valor. Las declaraciones se separan con punto y coma.

Unidades citadas: px, pt, in, cm, mm, em, rem y %. En font-size, em se calcula respecto del tamaño de fuente del padre; rem, respecto de la raíz.

09Listas de selectores

HTML del cuerpo

<header class="encabezado">
  <h1>Este es un título principal</h1>
  <p>Este es un párrafo en el encabezado. </p>
</header>
<section class="contenido">
  <h2>Sección de contenido</h2>
  <p>Este es un párrafo dentro de la sección de contenido. </p>
</section>
<footer>
  <p>Este es un párrafo en el pie de página. </p>
</footer>

CSS

.encabezado, footer {
  background-color: #f0f0f0;
  padding: 10px;
  box-shadow: rgb(150,150,150) 10px 10px 20px 10px;
}
h1, h2 { color: navy; text-decoration: underline; }
p { font-size: 16px; line-height: 1.5; margin-bottom: 10px; }

Resultado

Las comas permiten compartir declaraciones entre selectores. padding es el relleno interior; margin es el espacio exterior. El relleno no requiere un borde visible, a diferencia de lo que afirma la lectura.

11Palabras clave y tipos de datos

Palabras clave citadas: auto, smaller, larger, ease-in, ease-out y ease-in-out.

Valores citados

box-shadow: 2px 2px 4px rgba(0, 0, 0, 0.2);
font-family: Arial, Helvetica, sans-serif;
transform: rotate(45deg);
content: "Universidad Siglo 21";
color: #f00;
background-color: rgba(0, 0, 255, 0.5);
font: bold 16px sans-serif;

Los ángulos, cadenas y colores son tipos de datos CSS. content puede producir texto en un pseudoelemento, como ::before.

Corrección del ejemplo con barra

background-position: center / 50%;
background: #f0f0f0 center / 50% no-repeat;

12Combinadores y multiplicadores

La sintaxis formal describe qué valores acepta una propiedad. Los símbolos &&, ||, |, *, +, ? y los rangos no se escriben literalmente en una hoja de estilos.

NotaciónSignificadoExpresión citada
[]Agrupaciónfont: bold [ small && italic ] 16px/1.5 sans-serif;
YuxtaposiciónSecuencia ordenadafont: bold 16px sans-serif;
&&Todos, en cualquier ordenbackground: url('imagen.png') no-repeat && center;
||Uno o más, en cualquier ordenorder-style: solid || dotted || dashed;
|Una alternativatext-align: left | center | right;
*Cero o másfont: bold smaller* 16px sans-serif;
+Uno o másmargin: 10px 20px+;
?Opcionalborder-radius: 5px 10px?;
{}Rango de repeticionesfont-size: 14px {1,3};
#Lista separada por comasbox-shadow: 1px 1px 3px rgba(0,0,0,0.4)#;
!Al menos un valor del grupo[ font-size? line-height? ]!;
[min,max]Rango numérico inclusivo<integer [0,∞]>

Declaraciones válidas equivalentes

font: italic bold 16px/1.5 sans-serif;
text-align: center;
margin: 10px 20px;
border-radius: 5px 10px;
font-size: 14px;
box-shadow: 1px 1px 3px rgba(0,0,0,0.4);

La lectura también menciona reglas @layer, @import, @media, @document y @font-face, sin un ejemplo completo. @media se aplica en la sección de diseño responsivo.

14Herencia

HTML

<p>Texto verde con <em>color heredado</em>.</p>
<p>Texto verde con <em class="distinto">color sobrescrito</em>.</p>
<p>Texto verde con <em class="borde">borde heredado explícitamente</em>.</p>

CSS

p { color: green; border: medium solid; padding: 10px; }
em.distinto { color: blue; }
em.borde { border: inherit; }

Resultado

color se hereda por defecto; border no. inherit fuerza a tomar el valor del padre.
