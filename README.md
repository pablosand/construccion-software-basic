## Resumen del Módulo 1: HTML, CSS y JavaScript

El módulo 1, ubicado en [m1-html-css-javascript](m1-html-css-javascript/), introduce la construcción de páginas web mediante tres tecnologías complementarias: **HTML** para organizar el contenido, **CSS** para definir su presentación y **JavaScript** para incorporar comportamiento e interacción.

Sus cuatro lecturas avanzan desde la estructura de un documento HTML y el diseño responsivo hasta los fundamentos de programación, la manipulación del DOM y el manejo de eventos. El caso **Empresa Ficticia** permite observar la aplicación de estos conceptos en ejemplos de un sitio web.

Este repositorio está orientado a la enseñanza de Construcción de Software en un nivel básico. Este README documenta los módulos 1 y 2.

## Descripción del Módulo

El material está dirigido a estudiantes principiantes que desean comprender cómo se construye una página web y cómo se relacionan su estructura, presentación y comportamiento. Las lecturas contienen explicaciones, fragmentos de código y demostraciones en el navegador.

### Objetivos Educativos

- Identificar la función de HTML, CSS y JavaScript en una página web.
- Construir documentos HTML con elementos, atributos y estructura semántica.
- Aplicar estilos mediante selectores, reglas CSS, cascada y herencia.
- Adaptar la presentación a distintos tamaños de pantalla.
- Comprender variables, tipos de datos, operadores y estructuras de control en JavaScript.
- Trabajar con funciones, objetos, arreglos y conceptos iniciales de herencia.
- Consultar y modificar el DOM y responder a eventos del usuario.
- Integrar los conceptos estudiados en ejemplos del caso Empresa Ficticia.

## Estructura del Módulo

El módulo se organiza en **cuatro lecturas**, disponibles como páginas HTML:

### Lectura 1 - Fundamentos de HTML e Introducción a CSS

**Página:** [index_m1l1.html](m1-html-css-javascript/index_m1l1.html)

- Estructura semántica HTML5.
- Ejemplos de HTML y CSS aplicados al caso Empresa Ficticia.

**Conceptos:** estructura del contenido, semántica y separación entre contenido y presentación.

### Lectura 2 - CSS y Diseño Responsivo

**Página:** [index_m1l2.html](m1-html-css-javascript/index_m1l2.html)

- Propiedades, reglas y formas de aplicar CSS: en línea, interno y externo.
- Cascada, sobrescritura, sintaxis y unidades.
- Selectores de tipo, clase, ID y atributos; listas de selectores y estados de enlaces.
- Palabras clave, tipos de datos y notación de valores CSS.
- Cajas, colores, tamaños e herencia.
- Diseño responsivo y aplicación al caso Empresa Ficticia.

**Conceptos:** selección de elementos, resolución de estilos y adaptación visual.

### Lectura 3 - Fundamentos de JavaScript

**Página:** [index_m1l3.html](m1-html-css-javascript/index_m1l3.html)

- Ejecución de JavaScript y declaración de variables con `var`, `let` y `const`.
- Operadores, tipos de datos, condicionales y estructuras repetitivas.
- Funciones y uso de `this`.
- Objetos, métodos, constructores y `prototype`.
- Creación de objetos con `Object.create()` y trabajo con arreglos.
- Herencia prototípica, clases y `extends`.
- Aplicación de JavaScript al caso Empresa Ficticia.

**Conceptos:** lógica de programación, organización de datos y comportamiento mediante funciones y objetos.

### Lectura 4 - JavaScript en el Navegador, DOM y Eventos

**Página:** [index_m1l4.html](m1-html-css-javascript/index_m1l4.html)

- JavaScript en línea, interno y externo; carga de scripts.
- Objetos del navegador (BOM): `window`, `history`, `navigator`, `screen` y `location`.
- Interfaces del DOM y creación y modificación de elementos.
- Tipos de eventos y registro mediante atributos, propiedades y `addEventListener`.
- Integración de interacción y contenido dinámico en el caso Empresa Ficticia.

**Conceptos:** relación entre JavaScript, el navegador y el documento; interacción basada en eventos.

## Ruta de Aprendizaje Recomendada

1. **Estructura:** comenzar con la lectura 1 y reconocer los elementos de un documento HTML.
2. **Presentación:** continuar con la lectura 2 y experimentar con selectores, colores, tamaños y diseño responsivo.
3. **Programación:** estudiar la lectura 3 y analizar cómo cambian los resultados al modificar datos, condiciones y funciones.
4. **Interacción:** finalizar con la lectura 4 y relacionar eventos del usuario con modificaciones del DOM.

En cada lectura, revisar primero los conceptos y los fragmentos de código, observar las demostraciones y luego aplicar pequeñas modificaciones al ejemplo.

## Cómo Usar Este Módulo

### Requisitos

- Un navegador web moderno con JavaScript habilitado para las demostraciones interactivas.
- Un editor de texto o código, como Visual Studio Code, para practicar con los ejemplos.
- Conexión a Internet para las imágenes que se cargan desde servicios externos.

No se requiere compilar el código ni instalar un framework para consultar estas páginas.

### Para Estudiantes

1. Descargar o clonar el repositorio y abrir la carpeta del proyecto.
2. Abrir [la lectura 1](m1-html-css-javascript/index_m1l1.html) en el navegador desde los archivos locales.
3. Utilizar el índice lateral para recorrer los ejemplos y los enlaces del menú o del pie para cambiar de lectura.
4. Copiar los fragmentos que se deseen practicar a archivos propios y probar sus cambios en el navegador.
5. Utilizar las herramientas de desarrollo del navegador para inspeccionar elementos, estilos y mensajes de la consola.

### Para Instructores

1. Seguir la secuencia HTML, CSS, fundamentos de JavaScript y DOM/eventos.
2. Comparar cada fragmento de código con su resultado y explicar la función de cada tecnología.
3. Proponer modificaciones guiadas sobre el caso Empresa Ficticia.
4. Evaluar la comprensión mediante cambios en estructura, estilos y comportamiento, ajustando el ritmo al grupo.

Las actividades anteriores son sugerencias de uso del material, no archivos de ejercicios adicionales incluidos en el módulo.

## Resumen del Módulo 2: Java, Spring Boot y Persistencia

El módulo 2, ubicado en [m2-java-springboot-persistencia](m2-java-springboot-persistencia/), aborda la construcción de aplicaciones web del lado del servidor con **Java y Spring Boot**, la generación de vistas con **Thymeleaf** y la persistencia mediante **JPA, Hibernate, Spring Data JPA y MySQL**.

Sus cuatro lecturas avanzan desde arquitecturas y componentes Java hasta la implementación del **MVP Empresa Global**, una aplicación para listar y registrar productos. Incluyen fragmentos de código, diagramas de arquitectura, capturas de herramientas y referencias a proyectos Java. Aquí MVP significa producto mínimo viable, no el patrón Model-View-Presenter.

### Objetivos Educativos

- Distinguir las responsabilidades de vista, controlador, servicio, dominio, repositorio y base de datos.
- Reconocer POJO, JavaBean, EJB, Servlet, JSP, JSF y beans administrados por Spring.
- Crear la estructura de un proyecto Spring Boot mediante Spring Initializr y Maven.
- Aplicar inyección de dependencias, mapeos Spring MVC y renderizado con Thymeleaf.
- Comprender ORM y la relación entre JDBC, JPA, Hibernate y Spring Data JPA.
- Mapear entidades, identificadores, campos, relaciones y objetos embebidos con JPA.
- Utilizar SQL y repositorios para consultar y modificar datos, incluyendo paginación y ordenación.
- Integrar las capas de una aplicación Spring Boot con persistencia MySQL.

### Estructura del Módulo

#### Lectura 1 - Java y Arquitectura Web

**Página:** [index_m2l1.html](m2-java-springboot-persistencia/index_m2l1.html)

- Arquitecturas monolíticas, en capas, MVC, microservicios y n-capas.
- Maven y Gradle para dependencias y construcción de proyectos.
- JavaBean serializable, Enterprise JavaBeans y POJO.
- Beans de Spring con `@Component` y configuración con `@Bean`.
- Entidades JPA, vistas JSP y JSF, y Servlet.
- Diagrama de arquitectura de ejemplo para productos y pedidos con Spring Boot y MySQL.

**Conceptos:** separación de responsabilidades y diferencias entre componentes Java y tecnologías web.

#### Lectura 2 - Aplicaciones con Spring Boot

**Página:** [index_m2l2.html](m2-java-springboot-persistencia/index_m2l2.html)

- Expresiones, fragmentos y layouts Thymeleaf.
- Inyección de dependencias y herramientas del ecosistema Spring.
- Creación del proyecto con Spring Initializr: capturas, dependencias Maven, clase principal y propiedades.
- Controladores, modelo y vistas; mapeos de solicitudes y manejo de excepciones.
- Servicios, transacciones y ciclo de vida de los beans.
- Ejemplo integrado con `Elemento`, `ElementoServicio`, `Controlador` y la plantilla `info.html`.
- Captura del proyecto en IntelliJ IDEA y enlace al [código Java de demospringboot](https://github.com/pablosand/construccion-software-basic/tree/main/m2-java-springboot-persistencia/demospringboot).

**Conceptos:** configuración de Spring Boot, colaboración entre componentes y generación de HTML en el servidor.

#### Lectura 3 - Persistencia Java y JPA

**Página:** [index_m2l3.html](m2-java-springboot-persistencia/index_m2l3.html)

- ORM y desajuste entre el modelo de objetos y el modelo relacional.
- Funciones de JDBC, JPA e Hibernate.
- Entidades, tablas, identificadores y mapeo de campos.
- Relaciones entre entidades JPA.
- Consultas con Spring Data JPA y eventos del ciclo de vida de las entidades.
- Objetos embebidos y repaso de persistencia.

**Conceptos:** correspondencia entre objetos Java y datos relacionales.

#### Lectura 4 - SQL y Spring Data JPA

**Página:** [index_m2l4.html](m2-java-springboot-persistencia/index_m2l4.html)

- SQL DDL para definir estructuras, DML para consultar y modificar datos, y DCL para permisos.
- Repositorios Spring Data JPA: CRUD, paginación, ordenación y consultas personalizadas.
- Arquitectura del MVP Empresa Global: navegador, aplicación Spring Boot y MySQL.
- Guía de creación con Initializr, estructura de archivos, configuración y ejecución con Maven.
- Implementación de `Producto`, `ProductoRepositorio`, `ProductoServicio` y `ProductoControlador`.
- Plantillas Thymeleaf para listar y registrar productos, y referencias al código del proyecto.

**Conceptos:** integración de una aplicación web por capas con una base de datos persistente.

### Ruta de Aprendizaje Recomendada

1. **Arquitectura:** estudiar la lectura 1 y reconocer qué responsabilidad corresponde a cada componente.
2. **Aplicación web:** continuar con la lectura 2, crear un proyecto con Initializr y relacionar controlador, servicio, dominio y vista.
3. **Persistencia:** revisar la lectura 3 y analizar cómo se mapean los objetos Java a tablas y relaciones.
4. **Integración:** completar la lectura 4 e implementar el MVP, comprobando el registro, listado y persistencia de productos tras reiniciar la aplicación.

### Cómo Usar Este Módulo

Para consultar las lecturas basta con un navegador moderno: abrir [la lectura 1](m2-java-springboot-persistencia/index_m2l1.html) desde los archivos locales y utilizar el índice lateral y los enlaces entre páginas. Las capturas se encuentran en la carpeta [images](m2-java-springboot-persistencia/images/).

Para implementar los ejemplos Spring Boot se requiere:

- Un JDK compatible con la versión estable de Spring Boot seleccionada en Initializr.
- IntelliJ IDEA u otro editor o IDE con soporte para Java y Maven.
- Conexión a Internet para Spring Initializr, la descarga de dependencias y los repositorios enlazados.
- MySQL disponible y una base de datos con permisos para el usuario de la aplicación cuando se practique persistencia.
- Maven o el Maven Wrapper generado con el proyecto.

En el MVP, configurar la conexión en `application.properties` y las variables de entorno `DB_USERNAME` y `DB_PASSWORD`. Desde la raíz del proyecto Java generado, ejecutar `.\mvnw.cmd spring-boot:run` en Windows o `./mvnw spring-boot:run` en Linux/macOS; también se puede ejecutar `DemoSpringJPAApplication` desde el IDE. La aplicación se consulta en `http://localhost:8080/productos`.

### Notas Importantes

- Las páginas HTML son material didáctico, no una aplicación Spring Boot ejecutable. Para practicar, crear el proyecto Java y reunir las clases, plantillas, propiedades y dependencias indicadas.
- Algunos fragmentos ilustran conceptos y requieren tipos o configuración adicionales; consultar las notas de cada lectura antes de compilarlos.
- Las versiones mostradas en capturas son referencias del material: verificar la disponibilidad y compatibilidad de Spring Boot y Java al generar un proyecto.
- Los paquetes `jakarta.*` y `javax.*` corresponden a generaciones distintas de las APIs; utilizar los apropiados para las dependencias del proyecto.
- `spring.jpa.hibernate.ddl-auto=update` se utiliza en el ejemplo de desarrollo; en producción conviene gestionar los cambios de esquema mediante migraciones.
- No guardar credenciales reales en el repositorio. Utilizar variables de entorno para la conexión a MySQL.
