01SQL DDL: estructura y tablas

DDL (Data Definition Language o Lenguage de Definición de Datos) define y modifica la estructura de la base de datos: tablas, columnas, restricciones, índices y vistas.

CREATE TABLE

CREATE TABLE Producto (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(120) NOT NULL,
    precio DECIMAL(10, 2) NOT NULL
);

ALTER TABLE

ALTER TABLE Producto
ADD COLUMN descripcion TEXT;

CREATE INDEX

CREATE INDEX idx_producto_nombre
ON Producto (nombre);

CREATE VIEW

CREATE VIEW productos_catalogo AS
SELECT id, nombre, precio
FROM Producto;

DROP TABLE

DROP TABLE Producto;

DROP TABLE elimina la tabla y sus datos; usarlo con precaución.

02SQL DML: consultar y modificar datos

DML (Data Manipulation Language o Lenguaje de Manipulación de Datos) consulta e inserta, actualiza o elimina registros. La lectura da las formas generales; los ejemplos se completan usando la tabla Producto de la sección anterior. También existe la clasificación DQL (Data Query Language o Lenguaje de Consulta de Datos) para solo lecturas o consultas en objetos de bases de datos.

SELECT

SELECT nombre, precio
FROM Producto
WHERE precio > 0
ORDER BY nombre ASC;

INSERT INTO

INSERT INTO Producto (nombre, precio)
VALUES ('Teclado', 25000.00);

UPDATE

UPDATE Producto
SET precio = 27500.00
WHERE id = 1;

DELETE

DELETE FROM Producto
WHERE id = 1;

Las sentencias UPDATE y DELETE llevan una condición WHERE para afectar solo los registros previstos.

Transacción

START TRANSACTION;

UPDATE Producto
SET precio = 27500.00
WHERE id = 1;

COMMIT;
-- Ante un error, cancelar con: ROLLBACK;

03SQL DCL: permisos

DCL (Data Control Language o Lenguaje de Control de Datos) administra los privilegios que tienen los usuarios sobre los objetos de la base de datos.

GRANT

GRANT SELECT, INSERT, UPDATE
ON demo_springJPA.Producto
TO 'app_user'@'localhost';

REVOKE

REVOKE UPDATE
ON demo_springJPA.Producto
FROM 'app_user'@'localhost';

La sintaxis para crear usuarios y otorgar privilegios puede variar entre DBMS.

04Repositorio Spring Data JPA y CRUD

Al extender JpaRepository, Spring Data JPA proporciona operaciones comunes sin implementar SQL manualmente.

Entidad de ejemplo

import jakarta.persistence.Entity;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;

@Entity
public class Usuario {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String nombre;

    protected Usuario() {
    }

    public Usuario(String nombre) {
        this.nombre = nombre;
    }

    public Long getId() { return id; }
    public String getNombre() { return nombre; }
}

Interfaz de repositorio

import org.springframework.data.jpa.repository.JpaRepository;

public interface UsuarioRepositorio
        extends JpaRepository<Usuario, Long> {
}

Operaciones básicas

Usuario guardado = usuarioRepositorio.save(new Usuario("Juan"));

Optional<Usuario> encontrado =
        usuarioRepositorio.findById(guardado.getId());

List<Usuario> usuarios = usuarioRepositorio.findAll();
long cantidad = usuarioRepositorio.count();

usuarioRepositorio.deleteById(guardado.getId());

Los fragmentos CRUD son una demostración de uso; deben ejecutarse desde un componente Spring que reciba UsuarioRepositorio por inyección.

05Spring Data JPA: paginación y ordenación

Primera página, diez usuarios

import org.springframework.data.domain.Page;
import org.springframework.data.domain.PageRequest;

Page<Usuario> pagina = usuarioRepositorio.findAll(
        PageRequest.of(0, 10)
);

Orden ascendente por nombre

import org.springframework.data.domain.Sort;

List<Usuario> usuariosOrdenados = usuarioRepositorio.findAll(
        Sort.by(Sort.Direction.ASC, "nombre")
);

Los índices de página empiezan en 0. Diez registros por página y orden ascendente por nombre.

06Spring Data JPA: consultas personalizadas

Consulta JPQL con @Query

import java.util.List;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.data.jpa.repository.Query;
import org.springframework.data.repository.query.Param;

public interface UsuarioRepositorio
        extends JpaRepository<Usuario, Long> {
    @Query("SELECT u FROM Usuario u WHERE u.nombre = :nombre")
    List<Usuario> findByNombre(@Param("nombre") String nombre);
}

Consultas derivadas del nombre del método

List<Usuario> findByNombre(String nombre);

List<Usuario> findByNombreContaining(String nombreParte);

El primer método busca una coincidencia exacta; el segundo busca nombres que contienen el texto indicado.

07MVP Empresa Global

El MVP gestiona productos en una tienda en línea mediante un formulario, persistencia MySQL y una lista de productos. Se separan modelo, repositorio, servicio, controlador y vistas.

  1. El usuario envía el formulario de producto.
  2. El controlador recibe los datos y delega la lógica al servicio.
  3. El servicio usa el repositorio para guardar o recuperar entidades.
  4. Thymeleaf presenta la lista o el formulario con los datos del modelo.

09MVP: conexión MySQL

Ubicación: src/main/resources/application.properties. Sustituye las variables de entorno por las credenciales configuradas en tu entorno.

spring.datasource.url=jdbc:mysql://localhost:3306/demo_springJPA
spring.datasource.username=${DB_USERNAME}
spring.datasource.password=${DB_PASSWORD}
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true

La opción update permite a Hibernate ajustar el esquema a las entidades. En producción conviene gestionar cambios de esquema con migraciones.

10MVP: entidad Producto

La entidad representa la tabla de productos. La lectura describe los campos id, nombre, precio y descripcion.

package com.ecommerce.productos;

import jakarta.persistence.Entity;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;
import java.math.BigDecimal;

@Entity
public class Producto {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String nombre;
    private BigDecimal precio;
    private String descripcion;

    public Producto() {
    }

    public Producto(String nombre, BigDecimal precio, String descripcion) {
        this.nombre = nombre;
        this.precio = precio;
        this.descripcion = descripcion;
    }

    public Long getId() { return id; }
    public String getNombre() { return nombre; }
    public BigDecimal getPrecio() { return precio; }
    public String getDescripcion() { return descripcion; }

    public void setNombre(String nombre) { this.nombre = nombre; }
    public void setPrecio(BigDecimal precio) { this.precio = precio; }
    public void setDescripcion(String descripcion) { this.descripcion = descripcion; }
}

12MVP: servicio de productos

El servicio concentra la lógica de negocio y delega la persistencia al repositorio.

package com.ecommerce.productos;

import java.util.List;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
@Transactional
public class ProductoServicio {
    private final ProductoRepositorio repositorio;

    public ProductoServicio(ProductoRepositorio repositorio) {
        this.repositorio = repositorio;
    }

    @Transactional(readOnly = true)
    public List<Producto> listarProductos() {
        return repositorio.findAll();
    }

    public Producto guardarProducto(Producto producto) {
        return repositorio.save(producto);
    }
}

13MVP: controlador de productos

El controlador entrega la lista de productos, muestra el formulario y procesa su envío.

package com.ecommerce.productos;

import java.math.BigDecimal;
import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.ModelAttribute;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestMapping;

@Controller
@RequestMapping("/productos")
public class ProductoControlador {
    private final ProductoServicio servicio;

    public ProductoControlador(ProductoServicio servicio) {
        this.servicio = servicio;
    }

    @GetMapping
    public String listarProductos(Model modelo) {
        modelo.addAttribute("productos", servicio.listarProductos());
        return "productos/lista";
    }

    @GetMapping("/nuevo")
    public String mostrarFormulario(Model modelo) {
        modelo.addAttribute("producto", new Producto("", BigDecimal.ZERO, ""));
        return "productos/formulario";
    }

    @PostMapping
    public String guardarProducto(@ModelAttribute Producto producto) {
        servicio.guardarProducto(producto);
        return "redirect:/productos";
    }
}
