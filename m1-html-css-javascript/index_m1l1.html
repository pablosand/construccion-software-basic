01Elementos y atributos

Un párrafo tiene una etiqueta de apertura y otra de cierre. br produce un salto de línea; lang="es" indica el idioma del documento.

<html lang="es">
  <body>
    <p>Universidad Siglo 21<br>Mi primer documento HTML</p>
  </body>
</html>

02Documento HTML básico

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Mi primer documento HTML</title>
</head>
<body>
  <p>Universidad Siglo 21</p>
</body>
</html>

Resultado

03Elementos de la cabecera

<title>Mi primer documento HTML</title>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<link rel="stylesheet" type="text/css" href="estilo.css">

El título aparece en la pestaña del navegador. Los metadatos configuran la codificación y la ventana gráfica. link vincula la hoja CSS externa.

09Empresa Ficticia: HTML

Ejemplo completo de la lectura, reunido e indentado. Incluye la función JavaScript básica mostrarMensaje().

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Empresa Ficticia - Agencia de Marketing Digital</title>
  <link rel="stylesheet" type="text/css" href="estilo.css">
  <script>
    function mostrarMensaje() {
      alert('¡Bienvenido a Empresa Ficticia!');
    }
  </script>
</head>
<body>
  <h1>Empresa Ficticia</h1>
  <p>Agencia de marketing digital fundada en 2020 en Córdoba, Argentina</p>
  <p>Nos especializamos en
    <span class="texto-en-linea">estrategias de marketing innovadoras y efectivas</span>.
  </p>
  <a href="https://www.empresaficticia.com.ar">Visita nuestro sitio web</a>
  <ul>
    <li>Gestión de redes sociales</li>
    <li>SEO (Optimización para Motores de Búsqueda)</li>
    <li>Marketing de contenidos</li>
  </ul>
  <img src="logo _ empresa _ ficticia.jpg" alt="Logo de Empresa Ficticia">
  <button onclick="mostrarMensaje()">Conoce más sobre nosotros</button>
  <div>
    <p>Ayudamos a las empresas a crecer en el mundo digital</p>
    <p>Nuestro enfoque personalizado asegura el éxito de nuestros clientes</p>
  </div>
</body>
</html>

10Empresa Ficticia: CSS

estilo.css

body {
  font-family: Arial, sans-serif;
}

h1 {
  color: blue;
}

.texto-en-linea {
  color: red;
}

body establece la tipografía; h1 colorea el título de azul; el selector de clase .texto-en-linea aplica rojo al texto del span.
